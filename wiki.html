QuranPDF Wiki

A detailed guide to the lightweight QuranPDF website, its structure, behavior, customization points, and deployment workflow.

QuranPDF is a static HTML application that displays the Madani Mushaf in an embedded PDF viewer. It is designed to be simple to host, easy to understand, and comfortable to use in a browser.

View the source repository · Open the live site

Features

Focused reader

A dark layout keeps attention on the embedded Madani Mushaf PDF.

Loading experience

A spinner and status message appear while the external document initializes.

Subtle motion

The title types in and the document panel enters after loading.

Static hosting

No database, backend, build system, or dependency installation is needed.

How the application works

  1. The browser loads index.html.
  2. The page creates a loading overlay and an iframe for the PDF.
  3. The iframe requests the PDF from the Internet Archive URL.
  4. When the iframe emits load, JavaScript adds classes to hide the loader, animate the heading, and reveal the reader.
quranpdf/
├── index.html   # Reader page and inline CSS/JavaScript
├── README.md    # Repository documentation
└── wiki.html    # This browser-based wiki
External document: the PDF is not stored in this repository. The reader depends on the availability and embedding policy of the external PDF host.

Run the project locally

Clone or download the repository, then either open index.html directly or serve the folder over HTTP. An HTTP server is recommended because browser security and PDF behavior can vary with file:// URLs.

python3 -m http.server 8000

Visit http://localhost:8000/. The wiki is available at http://localhost:8000/wiki.html.

Customize the project

Change the document

Update the src attribute of the iframe in index.html with a stable HTTPS PDF URL. Confirm that the document can legally be linked and that its host allows iframe embedding.

Change the appearance

All reader styles currently live in the <style> block of index.html. The main wiki colors are defined as CSS variables near the top of this file, making the wiki theme easy to adjust.

Improve fallback behavior

A production-ready version can add a direct “Open PDF” link, an iframe timeout message, and a retry button in case the external service is unavailable.

Deploy with GitHub Pages

  1. Open repository settings on GitHub.
  2. Go to Pages.
  3. Select the main branch and the repository root as the source.
  4. Save, wait for the workflow to finish, and open the generated Pages URL.

The expected pages are / for the reader and /wiki.html for this guide.

Troubleshooting

Blank PDF area

Open the PDF URL directly, check your connection, and inspect the browser console. The external host may be unavailable or may block embedding.

Loader remains visible

The loader is hidden after the iframe load event. If the remote request fails, add a fallback timeout and direct-link message to the page.

Old GitHub Pages content

Confirm that Pages deploys from main, wait for deployment completion, and hard-refresh the browser.

Mobile layout issues

Test portrait and landscape orientations. Adjust the reader height and add responsive CSS if browser controls leave too little vertical space.

Contributing and responsible use

Keep changes focused, test in current desktop and mobile browsers, and include screenshots for visual changes. Do not commit credentials or private documents.

Before replacing or downloading the PDF, review its copyright, license, attribution, and redistribution terms. This repository currently has no license file, so no additional reuse permission should be assumed for the project code.
